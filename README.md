# Clarity Intensive for Founders — Landing Page

Single-page static site. Open `index.html` in any browser.

Sibling to `strategic-clarity-intensive` (clarity.jonahlarkin.com). Same event, same date, same Square checkout. Founder-oriented copy.

## Structure
- `index.html` — the page (inline CSS, no build step)
- `img/hero.jpg` — full-bleed hero background
- `img/journal.jpg` — "24 hours" section inline image
- `img/bluff.jpg` — cinematic between-section band
- `CNAME` — `founders.jonahlarkin.com`

## Publishing
Enable GitHub Pages on the `main` branch, root directory. Set custom domain to `founders.jonahlarkin.com`. Add DNS CNAME record: `founders` → `jonah784.github.io`.
